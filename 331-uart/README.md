# Практика 3.3. Периферия ввода-вывода

| Пункт | Команды |
| --- | --- |
| 3.3.1 | `edge pp`, `edge od` измеряют время пересечения 2 В на подъёме и 1,3 В на спаде. |
| 3.3.2 | `loop internal`, `loop pins` выбирают петлю UART0. `echo <text>` проверяет обмен. |
| 3.3.3 | `link <text>`, `baud_shift <percent>`, `text` и `parity <rx> <tx>` проверяют обмен UART0 и UART1. |
| 3.3.4 | `block irq`, `block poll` сравнивают приём 64 байтов с прерыванием и чтением FIFO после передачи. |
| 3.3.5 | `scope <baud> <text>` снимает 4096 отсчётов с GP0 через АЦП и DMA с частотой 500 кГц. |

## Учебный прогон

В `device-3-3-*.log` записаны ответы прошивки, собранной для компьютера с моделью периферии. Модель рассчитывает напряжение RC-цепи 1 кОм и 4,7 мкФ с подтяжкой 60 кОм, моделирует делитель UART, отсчёты приёмника и FIFO на 32 байта. Осциллограммы построены из модельных отсчётов GP0 на 115 200 и 9600 бит/с. Физическая плата не использовалась. Нулевой серийный номер в логах обозначает учебный прогон.

Для воспроизведения из корня репозитория нужны GCC, Python и matplotlib.

```sh
bash 331-uart/offline/run.sh
```

## Прошивка Pico

```sh
cmake -S 331-uart -B 331-uart/build
cmake --build 331-uart/build
```

Для 3.3.1 соедините GP22 через резистор 1 кОм с узлом GP26, а конденсатор 4,7 мкФ подключите от узла к AGND. Для внешней петли 3.3.2 соедините GP0 с GP1. Для 3.3.3–3.3.5 снимите перемычку петли, соедините GP0 с GP9 и GP8 с GP1. Для 3.3.5 отсоедините RC-цепь от GP26 и соедините GP26 с GP0. Скрипты `check-3-3-*.py` запускаются из папки проекта с установленным pyserial. Для 3.3.1 передайте ёмкость конденсатора, например `python check-3-3-1.py 4.7`.
